# DvpReceipt
The confirmation shown after a repo opens, liquidates or repays: both legs of one atomic transaction.

**Provide:** what each side delivered and received (amount, asset, source), the settlement sentence and the TxHash. Opening: borrower delivers collateral, receives USDC. Repay: borrower delivers principal plus interest, receives collateral. Liquidation: liquidator delivers USDC, receives collateral.

This is the demo's key visual proof: both legs, one transaction hash.
