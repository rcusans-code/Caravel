# TxHash
A shortened transaction hash, contract ID or account, linked to the Stellar explorer.

**Provide:** the kind (TX, CONTRACT, ACCOUNT), the full value (shown as first 4 + … + last 4) and, where one exists, the stellar.expert testnet URL. Put the full value in `title` so it can be read on hover.

Every on-chain action in the demo shows its TxHash right after confirmation; that link is how judges verify the DvP happened.
