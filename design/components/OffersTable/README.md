# OffersTable
The offers board and position lists as a dense table for comparing terms.

**Provide:** rows of offers or repos with id, amount, APR, term, haircut, collateral, status and an optional row action. Wrap in `.cv-table-wrap` (scrolls sideways on phones); give numeric cells class `r cv-num` so figures right-align in mono.

Headers sit on `surface-sunken` with a `line-strong` (ecru) rule. APR cells use `brand`. Row actions are small secondary buttons; never a primary button per row.
