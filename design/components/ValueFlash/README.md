# ValueFlash
Marks a figure that has just changed: its ground glows once and fades over 1.2s.

**Provide:** after you update the text, call `Caravel.flash(el)` (gold, a neutral change) or `Caravel.flash(el, "up" | "down")` (healthy or defaulted soft ground) when direction matters, as with collateral cover. Give the element a little horizontal padding so the glow has room.

Plays once per change, never on a timer. Flash only figures a person is comparing (NAV, cover, rate); never decorative numbers. Pair a direction flash with the number itself, never color alone. Reduced motion: no flash; the new value simply appears.
